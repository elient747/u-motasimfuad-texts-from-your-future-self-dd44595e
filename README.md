One original line, 1 to 200 characters: a text from your future self — stop doomscrolling, drink some water, because in 10 years your knees file a formal complaint.

## Run it

```sh
python3 -P -s main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
